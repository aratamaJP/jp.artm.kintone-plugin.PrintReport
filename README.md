# Getting Started

## 開発環境準備

1. 次のコマンドを実行する
   npm install

2. 当プラグイン用の「private.ppk」をルートディレクトリに配置する

3. 「.env.example」を複製し「.env」を作成する


## 動作試験環境への、プラグインアップロード

1. 次のコマンドを実行する
   npm run build-upload


## 配布用パッケージの作成

1. 次のコマンドを実行する
   npm run build:prod
